# AutoRB Knowledge Base (llm-wiki)

This is a personal, incrementally-maintained wiki for the AutoRB project. Start at **[[index]]**.

It follows the [llm-wiki guide](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f/raw/ac46de1ad27f92b28ac95459c782c07f6b8c964a/llm-wiki.md): `index.md` is the entry point, `log.md` is the change ledger, and every topic page is a living document linked with `[[wikilinks]]`. The `.obsidian/` folder makes it openable as an Obsidian vault with a navigable graph.
