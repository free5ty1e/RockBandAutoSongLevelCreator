AutoRB

Turn any song into a playable Rock Band 3 CON and Clone Hero chart — vocals, guitar, bass, drums & keys, transcribed by AI. Your audio never leaves your machine.

The control panel runs on your computer. Charting needs real compute (AI stem separation, vocal alignment, instrument transcription), so the working UI is served by a small local engine — this page just gets you there in three commands.

1 · Install

Requires Python 3.11–3.13 and FFmpeg (with libvorbis — on macOS use brew install ffmpeg-full).

git clone https://github.com/free5ty1e/RockBandAutoSongLevelCreator.git
cd RockBandAutoSongLevelCreator
python3 -m venv venv && source venv/bin/activate    # Windows: .\venv\Scripts\Activate.ps1
pip install -e .

The heavy ML dependencies (PyTorch, Demucs, WhisperX) download on the first install — a few minutes.

2 · Start the engine

python -m webui.server        # or: autorb-webui

You'll see AutoRB web engine: http://127.0.0.1:7860. (Ports/paths configurable via AUTORB_WEBUI_PORT / AUTORB_WEBUI_JOBS.)

3 · Open the control panel

→ http://127.0.0.1:7860 — open it in your browser.

Drop in an MP3 (or pre-separated stems) + optional LRC lyrics, pick your options, and chart the song. Live progress, artifact downloads, batch multi-song PS4 packs, an output folder picker — it's all there. Works on Windows, macOS, and Linux.

What you get

  • Full-band charts: guitar, bass, drums, keys + vocals at all four difficulties, following Rock Band authoring rules.
  • Rock Band 3 CON files (playable on RPCS3/modded PS4 via the built-in ForgeTool PKG builder) and Clone Hero song folders for instant computer playtesting.
  • Batches: package several songs into one multi-song CON and one PS4 PKG, re-deployable with a stable ID.
  • Optional LRC: no lyrics file? The vocals are transcribed automatically. Instrumentals work too.

Prefer the command line?

python -m autorb.cli "song.mp3" \
  --artist "Artist" --title "Title" \
  --build-clone-hero --build-pkg

Same pipeline, same options — see the README for the full flag reference.

AutoRB runs everything locally: Demucs AI stem separation → tempo detection → WhisperX vocal alignment → instrument transcription → Rock Band CON packaging. Nothing is uploaded anywhere. Source & docs on GitHub.
