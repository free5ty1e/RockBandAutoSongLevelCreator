AutoRB — Chart Any Song for Rock Band

Drop in a song, get a playable Rock Band 3 CON + Clone Hero chart — vocals, guitar, bass, drums & keys, transcribed by AI.

🎛️ Connect to your AutoRB engine

This page is just the control panel. The charting engine — AI stem separation, transcription, packaging — runs on your own computer (your song files never leave your machine). Start it with two commands, then this page lights up:

Windows (PowerShell):git clone https://github.com/free5ty1e/RockBandAutoSongLevelCreator.git cd RockBandAutoSongLevelCreator pip install -e . python -m webui.server macOS / Linux (Terminal):git clone https://github.com/free5ty1e/RockBandAutoSongLevelCreator.git cd RockBandAutoSongLevelCreator pip install -e . python -m webui.server

Requires Python 3.11–3.13 and FFmpeg. Then keep this tab open and point it at the engine:

          What happens next

          • Clone Hero: copy the clone_hero/<artist> - <title> folder into your Clone Hero Songs folder, then Settings → Scan Songs.
          • Rock Band 3 (RPCS3/PS4): copy the .con (or the .pkg if you built one) per your setup's install guide.
          • Explore everything: the “Show in Explorer” button above opens the whole output folder — MOGG audio, MIDI chart, lyrics preview, validation report and more.
          AutoRB runs the full pipeline locally: Demucs AI stem separation → beat/tempo detection → WhisperX vocal alignment → Basic-Pitch/ADTOF instrument transcription → Rock Band CON packaging. Nothing is uploaded anywhere. Source & docs on GitHub.
