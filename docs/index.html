This page is just the control panel. The charting engine — AI stem separation, transcription, packaging — runs on your own computer (your song files never leave your machine). Start it with two commands, then this page lights up:

Windows (PowerShell):git clone https://github.com/free5ty1e/RockBandAutoSongLevelCreator.git cd RockBandAutoSongLevelCreator pip install -e . python -m webui.server macOS / Linux (Terminal):git clone https://github.com/free5ty1e/RockBandAutoSongLevelCreator.git cd RockBandAutoSongLevelCreator pip install -e . python -m webui.server

Requires Python 3.11–3.13 and FFmpeg. Then keep this tab open and point it at the engine:
